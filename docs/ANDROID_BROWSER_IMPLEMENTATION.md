# Yehaw Android browser implementation

Yehaw is the Android browser product. Its native application is implemented in Kotlin and uses Android System WebView for page rendering. The WebView/Chromium engine is provided by the Android device and is not bundled into the application.

See:
- `docs/YEHAW_ANDROID_BROWSER_ARCHITECTURE.md` for component and lifecycle design.
- `docs/NATIVE_ANDROID_BROWSER_STATUS.md` for implemented capabilities and outstanding release gates.
- `docs/SECURITY_AND_DATA_OPERATIONS.md` for the browser security and privacy model.

The previous Filipino directory application is retired and is not part of the Yehaw browser product.
