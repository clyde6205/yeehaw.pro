Status: editorial draft only. Verify every statement against the final signed release before publishing.

## App name
YeeHaw Browser

## Short description (under 80 characters)
A lightweight Android browser with tabs, private browsing and offline reading.

## Full description
Browse the web with a lightweight Android browser designed with resource-conscious features.

**Everyday browsing**
- Open HTTP and HTTPS websites.
- Manage multiple tabs and restore your browsing session.
- Choose a search engine.
- Find text on a page, share links and switch to desktop-site mode.
- Download files and upload files to websites.

**More control**
- Use a separate private-browsing profile.
- Manage bookmarks and browsing history stored on your device.
- Save selected pages as text-first offline reading snapshots.
- Use Data Saver options and memory-aware tab handling.

YeeHaw uses Android System WebView, which is provided and updated by your device. Website compatibility, performance and memory use vary by device, Android version, WebView provider and the websites you visit.

No account or sign-up is required.
