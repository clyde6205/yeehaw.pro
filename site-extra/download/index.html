Install

  1. Open this page on your phone and tap Download.
  2. Open the file. If asked, allow “Install unknown apps” for your browser or file manager.
  3. Optional: check the file against the SHA-256 above (for example sha256sum in Termux, or a checksum app).

Install check in CI: installs and launches on an Android 6 emulator limited to 1 GB RAM / 1 CPU core and on Android 12. Not yet measured on a physical phone.
