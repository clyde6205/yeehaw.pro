A deliberate engineering choice

Small app layer.
System-maintained web engine.

Yehaw uses Android System WebView, a Chromium-based engine supplied and updated by the device. This keeps Yehaw from shipping its own full Chromium engine inside the APK. Actual memory use and site compatibility depend on the device, Android version and installed WebView provider.

Current architecture
  • Native Kotlin Android application
  • Android System WebView rendering
  • Memory-aware background tab policy
  • Local SQLite browser data
  • Android DownloadManager handoff
  • No account sync service claimed or advertised
Development status

Building and validating in the open.

The project is in active development. Automated Android build and emulator checks are being run; device testing, security review, release signing and a public distribution package are still required before launch.
